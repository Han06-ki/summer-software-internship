# Summer Software Internship Homepage

This is my Week 1 internship website. It was built with HTML, CSS, TypeScript, Vite, GitHub, and Vercel.

## Project sections

- Hero section
- About me
- What I am learning
- Project log
- TinyURL coming soon
- What I learned this week
- Weekly goal validator

## TypeScript interactions

This project includes:

- Dark mode toggle
- Completed learning task counter
- Project log form that adds a new entry
- Weekly goal form validation
- Last updated timestamp

## How to run locally

1. Clone the repo:

```bash
git clone YOUR_GITHUB_REPO_URL
```

2. Go into the project folder:

```bash
cd summer-software-internship
```

3. Install dependencies:

```bash
npm install
```

4. Start the dev server:

```bash
npm run dev
```

5. Open the local URL shown in the terminal.

## How to build

```bash
npm run build
```
