# Week 1 Update

## What I built

This week I built a public homepage for my summer software internship. The website has a hero section, an about me section, a learning goals section, a project log, a TinyURL coming soon section, and a section explaining what I learned this week.

## Tools I used

I used HTML for the page structure, CSS for the design, TypeScript for the interactive features, Vite to run and build the project, Git to track changes, GitHub to store the repository, and Vercel to deploy the website.

## TypeScript features

I added a dark mode button, a completed task counter, a project log form, a weekly goal validator, and a last updated timestamp. These features use querySelector, functions, event listeners, and null checks.

## What I learned

I learned that HTML creates the structure of the page, CSS controls how the page looks, and TypeScript adds behavior. I also learned that browsers do not run TypeScript directly. Vite helps convert and serve the project so it can run in the browser.

## What I struggled with

The hardest part was understanding how TypeScript connects to the HTML through the DOM. I had to make sure each querySelector found the correct element and handle the case where an element could be null.

## What I am proud of

I am most proud of adding the interactive project log because it makes the page feel more like a real app instead of just a static website.

## Next steps

Next week, I want to keep improving my website and start building more real features. I also want to keep practicing Git commits, GitHub, and deployment.
